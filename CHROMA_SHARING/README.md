## How `Chroma_mid2.pptx`'s content was sourced

Per `rules.md` AI Coding Rule 5 (never fabricate validation numbers), every
result slide is either:
- a real output artifact already on disk under `outputs/` or `OUTPUT_RCWA/`
  (e.g. the composite-grating and trench vs.-Lumerical overlays), or
- generated by calling this repo's own library API (`Simulation`,
  `PlaneWaveExcitation`, etc.) with different sweep parameters — never a
  hand-drawn or invented curve, or
- for the two "Problems Faced" panels where the original wrong Lumerical
  export was never git-tracked and no longer exists (confirmed via
  `git log --follow` on the relevant `OUTPUT_RCWA/` files), a bar chart of
  the exact before/after numbers already recorded in `decisions.md`
  (ADR-034, ADR-036) — not a reconstructed curve.

The one exception, reconstructed rather than replayed from a saved
artifact: ADR-033's "before" polarization curve, rebuilt by evaluating the
exact pre-fix formula from `git show 9512570~1:structures/thin_film/custom_multistack.py`
through the current solver, then checked against the real saved
2026-08-12 run (peaks matched to <0.5%) before being trusted.

See `decisions.md` (ADR-033, ADR-034, ADR-035, ADR-036) and
`progress_log.md`'s 2026-08-17 through 2026-08-21 entries for the full
narrative these decks summarize.
